# Cliptx – Support Center

A lightweight, single-file support website for **Cliptx**, a Video & Photo Editor app by **DevXHive Technologies**. Designed to be hosted statically (GitHub Pages, Netlify, etc.) and serves as the app's public-facing legal and support hub.

## Pages

| Page | Description |
|------|-------------|
| 🛠 Support | Contact information and common issue guidance |
| 🔒 Privacy Policy | Full privacy policy covering data collection, third-party services, permissions, and user rights |
| 📄 Terms of Service | Full terms covering usage rules, community standards, subscriptions, IP, and liability |
| 🔐 Security | Technical security measures including authentication, encryption, and vulnerability reporting |
| 🗑 Delete Account | Step-by-step account deletion instructions and email request form |

## Tech Stack

- Pure HTML, CSS, and vanilla JavaScript — no dependencies, no build step
- Single file: `index.html`
- Client-side tab navigation (no page reloads)

## Usage

Just open `index.html` in any browser, or deploy it to any static hosting provider.

### GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set the source to the `main` branch, root directory
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`

### Netlify / Vercel

Drag and drop the repo folder into the Netlify or Vercel dashboard — no configuration needed.
